# TV Acceleration

**Русский** · [English](README.en.md)

Ускорение и чистка Android TV и Google TV: стиков, приставок и телевизоров. Одной кнопкой.

Вы включаете на телевизоре отладку (в программе есть инструкция с картинками) и нажимаете
**«Ускорить»**. Всё остальное программа делает сама, а в конце показывает отчёт «до/после».

Три кнопки:

- **Ускорить** — всё, что описано ниже;
- **Повторить после обновления** — если обновление прошивки что-то вернуло, программа найдёт это и
  исправит снова;
- **Вернуть как было** — телевизор возвращается в состояние до первого запуска программы.

## Что делает «Ускорить»

| Шаг | Что происходит |
|---|---|
| Резервная копия | Перед любым изменением сохраняется исходное состояние. Ничего не удаляется: приложения только отключаются. |
| Чистка | Отключает рекламу, слежку и предустановленный мусор по готовым спискам для 290+ моделей ([cleanyourtv](https://github.com/Gathin23/cleanyourtv)). Не трогает то, чем вы пользуетесь, и то, что вы ставили сами. Чистит кэш, ускоряет анимации. На слабых устройствах (1,5 ГБ памяти и меньше) ограничивает фоновые процессы. |
| Меню | Новый домашний экран в стиле Apple TV: в верхнем ряду — приложения, которыми вы пользуетесь чаще всего. Старый экран отключается, только когда новый точно запустился, иначе всё откатывается само. |
| Реклама | Блокирует рекламу через «Частный DNS» (AdGuard DNS). Если он недоступен из вашей сети — настройка возвращается сама. |
| Wi-Fi | Показывает сигнал, канал и частоту; убирает ложное «нет интернета». Устройство из другой страны не видит сети 5 ГГц — на Xiaomi программа сама меняет регион Wi-Fi, но только если это реально помогает. |
| Кнопки пульта | Netflix → YouTube (или SmartTube, если вы его поставили). Prime Video → rus tv на русском ТВ (программа сама поставит последнюю версию), на другом языке — что выберете. Без root. |
| Экран | Заставка-часы через 2 минуты, сон через 5 — экран не выгорает. Видео при этом не прерывается. |
| Проверка безопасности | Сверка с известными вирусами для ТВ-приставок ([Dr.Web](https://github.com/DoctorWebLtd/malware-iocs)), приложения не из Play Маркета, опасные права, микрофон и слежка за просмотром. Только смотрит, ничего не меняет. |
| Отчёт | Свободная память и запущенные приложения «до → после», что отключено — красиво, для скриншота. |

Все надписи — на языке телевизора: русский, если ТВ на русском, иначе английский.

## Как запустить

1. Скачайте программу для своего устройства (раздел Releases):
   - **Windows** — `TV-Acceleration-Windows.zip`, внутри `TV Acceleration.exe`.
     При первом запуске Windows может предупредить: «Подробнее → Выполнить в любом случае».
   - **Mac** — `TV-Acceleration-Mac.zip`, внутри `TV Acceleration.app`.
     При первом запуске: правый клик → «Открыть» → «Открыть».
   - **Android-телефон** (без компьютера) — `TV-Acceleration-Phone.apk`.
2. Телевизор и компьютер (или телефон) должны быть в одной сети Wi-Fi.
3. Включите отладку на телевизоре — в программе пошаговая инструкция с картинками:
   Настройки → Настройки устройства → Об устройстве → 7 раз нажмите на «Сборка» →
   назад → Для разработчиков → включите «Отладка по USB».
4. Нажмите «Найти телевизор». На ТВ появится «Разрешить отладку?» — отметьте «Всегда разрешать» и нажмите OK.
5. Нажмите «Ускорить» и подождите 3–4 минуты. Телевизор один раз перезагрузится — это проверка, что всё запускается.

Программа связи с телевизором (adb) скачивается с сайта Google сама при первом запуске.

## Совместимость

| Устройство | Статус |
|---|---|
| Xiaomi Mi TV Stick (MiTV-AESP0), Android TV 9 | ✅ Проверено |
| Другие Android TV и Google TV с Android 9–12 (Xiaomi Mi Box, Chromecast с Google TV, Sony, Philips, TCL, Hisense и др.) | 🟡 Должно работать |
| Android TV 13 и новее | 🟡 Должно работать, кроме переназначения кнопки Prime |
| Android TV 8 и старше | 🟡 Должно работать, кроме блокировки рекламы (нет «Частного DNS») |
| Amazon Fire TV (Fire OS) | 🟠 Частично: чистка, Wi-Fi, проверка безопасности; Fire OS не даёт сменить домашний экран |
| Samsung (Tizen), LG (webOS), Roku, Apple TV | ❌ Не поддерживается — это не Android |

На Google TV стандартный домашний экран нужен системе (без него некоторые устройства зависают при загрузке),
поэтому программа его не отключает; если новое меню из-за этого не становится главным, установка откатывается сама.

## Безопасность

- Перед первым изменением сохраняется исходное состояние; «Вернуть как было» возвращает именно его.
- Приложения только отключаются (`pm disable-user`), не удаляются. Удаляются лишь приложения, которые поставила сама программа (её меню).
- Никогда не трогается: системный интерфейс, настройки, сервисы Google и Play Маркет, клавиатура, пульт, Bluetooth, HDMI-входы, загрузочные сервисы производителя.
- Каждое рискованное действие проверяется сразу (меню, DNS, регион Wi-Fi) и при неудаче откатывается само.

## Для разработчиков

```
python3 -m tvaccel accelerate   # «Ускорить»
python3 -m tvaccel repeat       # «Повторить после обновления»
python3 -m tvaccel restore      # «Вернуть как было»
python3 -m tvaccel info         # только показать устройство
python3 app.py                  # окно программы
```

Нужен только Python 3.9+ (без сторонних библиотек). Меню для ТВ — `launcher/` (`sh launcher/build.sh`),
приложение для телефона — `phone/` (Gradle + Chaquopy). Сборки для Windows, Mac и телефона делает GitHub Actions
(`.github/workflows/build.yml`).
